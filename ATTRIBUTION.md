# Attribution and licensing checklist

Some architecture and explainability components in the supplied project are based on existing implementations. Before publication or GitHub release:

1. Keep the original copyright/license notices where required.
2. Cite the KAT architecture source identified in `model.py`.
3. Verify the upstream source and license for `efficient_kan.py`.
4. Verify the upstream source/license for any Grad-CAM implementation that was adapted into the project.
5. Distinguish project-specific training/evaluation code from third-party model implementations in the paper and repository.

This project should not be presented as entirely original software when it contains adapted third-party implementations.
